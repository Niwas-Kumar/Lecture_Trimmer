## Fix after 1.1.0 → building 1.1.1
- **Bug (ref 49DA901039D6):** a 2:16:10 lecture failed with "Transcript unit has invalid or out-of-source timestamps". The last 120s Groq section held only 10s of audio, and Whisper returned segments ending up to 20s past the source (its 30s padded window; "Thank you." hallucination). Word timings were already clamped; segment timings were not.
- **Fix:** `fit_segments_to_source` in `media/transcriber.py` clamps segment ends and drops segments that start past the end. It runs on fresh transcripts and on cached ones in `get_transcript`, so Retry reuses the saved transcript. Test: `test_segments_overhanging_the_final_short_section_fit_the_source`. 211 tests pass.
- 1.1.0 can't pick this up (frozen build, no update channel), so the installer was rebuilt as 1.1.1: `releases/1.1.1/LectureTrimmer-1.1.1-Setup.exe` (233 MB), smoke test passed. Installing it over 1.1.0 is up to the user.
